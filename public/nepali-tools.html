Typing and Preeti conversion do different jobs

Use Nepali Typing when you want to write new text using Roman letters. Use Preeti conversion for existing text encoded for the legacy Preeti font. A photograph or scan needs Private OCR first; review recognition errors before converting.

Check important dates against a trusted calendar

Bikram Sambat month lengths vary. The BS–AD converter shows its supported range, calendar library version and sample verification source. For official forms, verify the result with the issuing organization.
