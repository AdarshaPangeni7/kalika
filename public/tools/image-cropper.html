Crop a Photo Before Resizing It

Remove unwanted edges or prepare a photo’s shape before resizing it for a form. Drag a crop selection or enter exact pixel coordinates.

Drag across the image to select a rectangle. Use the pixel fields below for precise changes or keyboard access.

JPG, PNG or WebP inputs · up to 20 MB and 24 megapixels. Outputs up to 10,000 pixels on either side.

Cropping removes pixels outside the selection. It does not resize the remaining area. Use equal crop width and height for a square.

Change the shape without stretching the photo

A square form photo should start with a square crop rather than stretching a rectangular image. Select the area you want to keep, check that important details fit inside it, and download a cropped copy. Use the compressor’s output dimensions and KB limit next if your application specifies both.

How to use

  1. Choose a JPG, PNG or WebP image.
  2. Drag across the preview or enter the crop’s left, top, width and height in pixels.
  3. Select an output format and choose Crop image.
  4. Review the cropped preview, then select Download image.
  5. If needed, set dimensions and a KB limit in Image Compressor.

Frequently asked questions

How do I make a square crop?

Enter the same number for Crop width and Crop height, and adjust the left and top edges to keep the subject centered. The crop must fit inside the original image.

Can I crop without dragging?

Yes. Use the four labeled pixel fields with your keyboard. Left and top start at zero, and width and height describe the area to keep.

Does cropping change the output dimensions?

The output dimensions equal the selected crop width and height. To make that crop smaller or fit a KB limit, use Image Compressor afterward.

Are images uploaded or stored?

No. The image and crop are processed in this browser tab without file uploads or saved browser history.

Will the output exactly preserve the source quality?

Not always. JPG and WebP are re-encoded at 90% quality. PNG is lossless for the cropped pixels, but source metadata and animation are not preserved.
