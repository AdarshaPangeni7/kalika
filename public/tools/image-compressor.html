Free Image Compressor Online

Smaller files. More room. Keep the detail.

JPG, PNG or WebP · up to 20 MB and 24 megapixels. Output: JPG, with a white background for transparency.

Make an image smaller for email or sharing

Image compression reduces the data used to represent a picture. This tool exports a JPG at your chosen quality without changing the pixel dimensions. Lower quality can remove visible detail, so compare the result before using it. Compression without any quality loss is not guaranteed, and a source file that is already optimized may not become smaller.

How to use

  1. Choose an image from your device.
  2. Adjust the quality: lower values usually make smaller files.
  3. Compress the image. Your JPG downloads automatically.

A few useful answers

Will compression always make my file smaller?

No. A highly optimized image may already be smaller. We compare the sizes so you can decide whether to use the result.

What happens to transparent areas?

The output is a JPG. Transparent areas become white. Use the image resizer with PNG output if you need to keep transparency.

Does it change the image dimensions?

No. Compression retains the original pixel dimensions, subject to the 24-megapixel input limit.

Is photo metadata kept?

Canvas export does not intentionally retain your source file’s EXIF metadata. Keep your original if you need it.
