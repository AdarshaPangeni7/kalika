Compress an Image to a KB Limit

Make a photo fit an application form or email attachment. Choose a KB limit, check the file size and preview, then download when you are ready.

JPG, PNG or WebP inputs · up to 20 MB and 24 megapixels. Outputs up to 10,000 pixels on either side.

Target mode uses JPG or WebP. PNG is available in Choose quality mode; its size is not controlled by the quality slider. If you set dimensions, the tool will keep them rather than shrink further. 1 KB = 1,000 bytes.

Fit a photo under a form’s upload limit

A form can require both pixel dimensions and a maximum file size. Set its required dimensions here before compressing. If the required shape differs from your original, crop a copy first. Target mode tries different quality levels and can reduce dimensions only when allowed; it never offers a result above the chosen byte limit. Very small limits can make details unreadable, so inspect the preview and follow the form’s own requirements.

How to use

  1. Choose a JPG, PNG or WebP image.
  2. Select 50, 100 or 200 KB, or enter a custom maximum size.
  3. Choose JPG or WebP. Set required dimensions if your form specifies them.
  4. Select Compress image and inspect the result’s size, dimensions and readability.
  5. Select Download image only when you are happy with the preview.

Frequently asked questions

Can I compress a photo to 50 KB without changing its dimensions?

Set output dimensions or turn off Allow smaller dimensions. The tool then tries quality changes only. If it cannot meet the limit, it shows an error instead of downloading a file above the limit.

Does the result have exactly the requested size?

No. The target is a maximum, using 1 KB = 1,000 bytes. The result may be smaller. A tiny file can lose detail; a form may also impose separate minimum dimensions.

Can I keep a transparent background?

Choose WebP if the destination accepts it. JPG fills transparent areas with white. PNG keeps transparency but is available only in quality mode, without a target-size guarantee.

Are my photos uploaded or saved?

No. Processing and previews run in this browser tab. Kalika does not upload the image or save it in browser storage. Download the result before leaving.

Will compression always produce a smaller file?

No. Already optimized images may become larger when exported. The tool shows both sizes. Keep your original when it is more suitable.
