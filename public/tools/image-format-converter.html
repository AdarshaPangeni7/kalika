Convert an Image to JPG, PNG or WebP

Change an image’s file format without changing its dimensions. Preview JPG, PNG or WebP output before downloading it.

JPG, PNG or WebP inputs · up to 20 MB and 24 megapixels. Outputs up to 10,000 pixels on either side.

Quality affects JPG and WebP. PNG is lossless and ignores this slider. JPG fills transparent areas with white.

Choose a format the destination accepts

Use the file formats accepted by your upload form or app. JPG can suit photos, while PNG and WebP can retain transparent areas. Changing a file extension does not convert an image; this tool exports real image bytes in the selected format. Converting a JPG to PNG cannot recover detail lost in the JPG.

How to use

  1. Choose a JPG, PNG or WebP image.
  2. Select the output format required by your destination.
  3. Choose quality for JPG or WebP, then select Convert image.
  4. Inspect the preview and file size, then select Download image.

Frequently asked questions

Does this convert HEIC or SVG?

No. The supported inputs are JPG, PNG and WebP, up to 20 MB and 24 megapixels. Export another format to a supported image first.

Does conversion keep transparency?

PNG and WebP retain transparent areas. JPG replaces them with white. Preview the result before using it.

Will converting to PNG improve a blurry JPG?

No. Conversion does not recover missing detail, and PNG output may use more storage than the original JPG. The pixel dimensions stay the same.

Where is my image processed?

In this browser tab. The tool does not upload the image or save it in browser storage.

Does it keep animation or photo metadata?

No. Canvas export creates a still image and does not intentionally retain source EXIF metadata. Keep your original for animation and metadata.
