Free QR Code Generator Online

A simple scan to share a link or a little text.

Up to 500 UTF-8 bytes. A white quiet zone is included. Your QR code downloads as a PNG.

Create a static QR code for a link or text

A static QR code stores the supplied text directly in its pattern. Kalika does not create a tracking redirect or a hosted destination. A website link works only while that destination remains available, and changing the destination means generating a new code. Keep the white border and test the exported image at its intended print or display size.

How to use

  1. Paste a link or type short text.
  2. Choose the PNG size.
  3. Generate your QR code; the PNG downloads automatically.
  4. Scan the code with your phone to check it before sharing.

A few useful answers

Will this QR code expire?

The code itself does not expire. If it points to a website, that website must remain available.

Can I change the destination later?

This is a static QR code. Changing the text requires generating and sharing a new image.

Why does the QR image have a white border?

The quiet zone around the code helps cameras recognize its edges. Keep the border when printing or placing it in a design.
