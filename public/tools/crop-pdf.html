Crop PDF Online for Free

Trim visible margins from a PDF using precise measurements. Preview a page, choose which pages to crop and download a copy with a smaller visible page area.

One PDF up to 30 MB and 100 pages. Unlocked, flattened and unsigned documents only. Existing text remains as PDF text.

Cropping hides margins; it does not securely delete their content. This is not a redaction tool.

All pages remain in the file. Settings only affect the selected range. Recheck the preview after changing settings.

Crop PDF without uploading your document

Trim visible margins from a PDF using precise measurements. Preview a page, choose which pages to crop and download a copy with a smaller visible page area.

This tool works on a copy in your browser. It does not overwrite the original file, add OCR or preserve the validity of digital signatures. Review the downloaded document before sharing.

How to Use

  1. Choose a supported PDF.
  2. Enter the margins to trim in millimeters, relative to the displayed page.
  3. Choose all pages or a page range, and preview the crop.
  4. Create and download the cropped PDF.

Why Use This Tool

  • Keep document processing on your device.
  • Choose specific pages while retaining the whole document.
  • Preview the edited page before downloading.
  • Keep existing text without turning pages into images.

Frequently Asked Questions

Does cropping permanently delete hidden content?

No. Cropping changes the visible PDF page boundary. Content outside that boundary can remain in the file and may be recoverable. Do not use this tool to redact confidential information.

Can I crop rotated pages or mixed page sizes?

Margins are measured from the displayed top, bottom, left and right edges, including page rotation. The same settings apply to each selected page. If a page would become smaller than 12.7 mm in either direction, the operation stops so you can reduce the margins or choose another range.

Will cropping make my file smaller?

Not necessarily. The page content is retained rather than rasterized or deleted, so file size may remain similar or increase. Use Compress PDF separately when file size matters.

Where is my PDF processed?

The crop is applied in this browser tab without document uploads. Use one unlocked PDF up to 30 MB and 100 pages. Documents with form or signature fields are rejected; save an unsigned flattened copy first.
