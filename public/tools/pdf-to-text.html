Extract Text from a PDF

Copy selectable text into notes or a document. Review the result by page, then copy or download it as plain text.

Your document stays on this device. No account or file upload needed. How privacy works · All PDF tools

Up to 30 MB · 200 pages · 5 million extracted characters. Selectable text only; no OCR.

How to use

  1. Choose an unlocked PDF up to 30 MB and 200 pages.
  2. Select Extract text and wait for the page-by-page progress.
  3. Review the text, especially columns, spacing and special characters.
  4. Copy the text or download a TXT file; Clear removes the result from this tool.

Keep control of your document

No signup. Processing happens locally in this browser tab. Download and inspect your result before closing the page.

Read text from a scan

Scanned pages need recognition. Use Private OCR to read printed text in page images; this tool reads existing selectable text only. Open Private OCR.

Frequently asked questions

Can this read scanned documents?

No. This tool extracts text already stored in a PDF. Scanned images and letters drawn as shapes need OCR, which is not included. Pages with no selectable text are identified in the result.

Will the text keep its original layout?

No. Plain text does not keep fonts, images or page layout. Columns, tables, formulas and unusual font encodings can produce incorrect order or characters. Compare the result with your original PDF.

Are my documents uploaded or saved?

No. Your file is processed in the browser tab without a document upload or application storage. Website analytics are separate from file processing; see the Privacy page.

Can I cancel or clear an extraction?

Yes. Cancel stops the current extraction. Clear document and text removes the selected file and output from this tool. Downloaded files and text you copied to the clipboard remain under your control.
