Prepare a photo for an application

Check the form’s accepted formats, pixel dimensions and file-size limit before editing. Crop unwanted edges, set the required dimensions, then compress the finished photo if it needs to fit a KB limit. Compare the result with your original so important details remain readable.

Choose a format the destination accepts

A photograph, a transparent logo and a screenshot have different needs. Use the format converter when a destination requires JPG, PNG or WebP. JPG does not preserve transparency; changing the format also does not guarantee a smaller file. Check the preview and actual download size.
