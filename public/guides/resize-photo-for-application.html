Resize a photo to fit an online application's requirements

Written by Kalika · Updated October 8, 2026 · 2 min read

An application form may specify three different things: pixel dimensions, a file-size limit and an accepted format. Meeting one does not guarantee the others. Write down the form's exact requirements before changing your photo.

Separate dimensions from file size

A requirement such as 600 by 600 pixels describes the picture's shape and resolution. A limit such as 200 KB describes how much storage the file uses. These are examples, not universal application rules. Also check whether the form requires JPG or accepts PNG and WebP.

Keep the right shape

If the required photo has a different shape from your original, open Image Cropper first. Drag a rectangle or enter its pixel coordinates. For a square, enter equal crop width and height. Keep the face and other required details inside the selection, preview and download the cropped copy.

Open the cropped copy in Image Compressor. Enable Set output dimensions and enter the required width. Keep original proportions selected when the crop already has the correct shape; use independent width and height only when the source shape matches those requirements. Enlarging cannot recover missing detail.

Export an accepted format

Choose the format your form accepts. JPG replaces transparency with white; WebP can preserve transparency when accepted. If you only need to change formats, use Image Format Converter. Check the form’s own requirements before processing.

Set the file-size limit and preview

In Image Compressor, choose Target file size and select 50, 100 or 200 KB, or enter your form’s custom maximum. Choose JPG or WebP. When output dimensions are set, the tool keeps them and changes quality rather than shrinking further. If the limit cannot be reached, it shows an error; choose a larger permitted limit or review your dimensions. Select Compress image, inspect the actual file size and readability, then download. KB limits use 1,000 bytes per KB.

Check before submitting

Confirm the final dimensions, format and file size, then open the image at a comfortable viewing size. Check any separate requirements for background, framing or photo age against the form's own instructions. Kalika processes the photo locally; uploading the finished image to the application service is a separate step you choose.
