Comment taper É, Ç et œ sur un clavier QWERTY

Par Kalika · Publié le 8 octobre 2026 · Mis à jour le 8 octobre 2026 · 4 min de lecture

Vous devez écrire « École », « Ça va » ou « cœur », mais les lettres ne figurent pas sur votre clavier QWERTY. Pour quelques mots, vous pouvez insérer les caractères dans un éditeur en ligne. Pour écrire régulièrement en français, utilisez plutôt les options de votre appareil. Voici comment choisir et vérifier le résultat.

Ouvrir le clavier d’accents français

Pour un message court : insérer les lettres au curseur

  1. Ouvrez le clavier français Kalika et écrivez ou collez votre phrase.
  2. Dans « Ecole », placez le curseur après le E, puis sélectionnez cette lettre. Activez Majuscules et choisissez É pour obtenir « École ».
  3. Pour « cœur », sélectionnez les deux lettres oe dans « coeur », puis choisissez œ. C’est une seule lettre Unicode, pas une mise en forme du mot.
  4. Relisez la phrase, puis choisissez Copier le texte. Collez-la dans votre message ou document et vérifiez les caractères.

Les raccourcis de saisie sont désactivés au départ. Si vous les activez, c, devient ç, même dans une liste où vous vouliez une virgule. Juste après une substitution, Retour arrière ou Échap restaure la séquence tapée. Annuler fonctionne aussi. Laissez cette option désactivée pour du code ou du texte multilingue.

Sur Windows : choisir une disposition pour écrire souvent

Sur Windows 11, ouvrez Paramètres → Heure et langue → Langue et région. Dans les options linguistiques d’une langue, ouvrez Claviers puis Ajouter un clavier. Choisissez États-Unis international si cette disposition est proposée ; si elle manque, consultez les options de la langue correspondante.

Windows + Espace permet de basculer entre les dispositions installées. Sur États-Unis international, certaines touches d’accent attendent la lettre suivante : ce comportement est différent de celui d’un clavier américain standard. Vérifiez la disposition active avant de suivre un raccourci trouvé en ligne. Pour écrire une apostrophe seule avec une touche morte, il peut être nécessaire de la faire suivre d’une espace.

Consultez les étapes Microsoft pour ajouter et changer de clavier. Les intitulés peuvent varier selon la version de Windows. Si vous ne pouvez pas modifier un ordinateur partagé, l’éditeur en ligne permet de préparer seulement le passage nécessaire.

Sur Mac : maintenir une lettre ou utiliser Option

Dans une application compatible, maintenez une lettre pour ouvrir le menu des accents, puis choisissez le caractère proposé. Le menu n’existe pas pour toutes les touches ni dans toutes les applications.

Avec une disposition américaine, Option + E puis e donne é. Pour É, faites Option + E, relâchez les touches, puis Maj + E. Les combinaisons dépendent de la disposition : ouvrez le visualiseur de clavier pour trouver les caractères associés à Option et Maj, notamment Ç et œ. Le guide Apple sur les caractères accentués explique ces deux méthodes.

Sur iPhone et Android : essayer l’appui long

Sur iPhone, maintenez le doigt sur la lettre associée au caractère, puis choisissez une variante. Sur Android avec Gboard, un appui prolongé affiche également les accents et d’autres options. Les caractères proposés varient selon le clavier et la langue activée ; œ n’est pas nécessairement disponible dans chaque configuration.

Consultez les instructions officielles pour le clavier de l’iPhone et Gboard. Si un caractère manque, insérez-le dans Kalika puis copiez le passage.

Vérifier les majuscules, les ligatures et les espaces

Comparez votre résultat avec ces exemples : École · À demain · Ça va · cœur · Œuvre. Pour une majuscule dans Kalika, activez Majuscules avant le clic ; le texte déjà écrit ne change pas. La touche œ remplace votre sélection, donc sélectionnez précisément oe, sans inclure la lettre voisine.

Pour éviter qu’un signe de ponctuation reste seul au début d’une ligne, le panneau Ponctuation et espaces propose une espace insécable et une espace fine insécable. Insérez-les à l’endroit voulu ; l’éditeur ne corrige pas automatiquement la typographie. Choisir ou et où reste une question de sens : aucun bouton ne peut décider à votre place.

Enregistrer le résultat sans perdre les accents

Copier le texte conserve les caractères Unicode. Télécharger .txt produit un fichier UTF-8 avec les retours à la ligne, sans styles Word. Si une application affiche des caractères incorrects après importation, vérifiez qu’elle lit le fichier en UTF-8 et comparez avec le texte original.

Le texte de l’éditeur est traité dans votre onglet, sans envoi ni sauvegarde automatique. Copiez ou téléchargez votre travail avant de fermer ou recharger la page. Ouvrir le site nécessite une connexion ; le clavier d’accents ne modifie pas la disposition de votre système.
